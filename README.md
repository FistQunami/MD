# Marvel Heroes App

**Программирование мобильных устройств**  
Выполнена: Чернявской Алиной, МИБ-201-О-01

## Описание

Данная лабораторная работа является продолжением лабораторной работы 1, в которой было создано приложение для отображения списка героев из вселенной Marvel. В этой лабораторной работе мы заменили статичные данные на динамичные, получаемые через сетевые запросы к Marvel API.

Приложение теперь использует данные из сети для отображения списка героев и информации о каждом герое.

## Функционал

1. Прокручиваемый список героев Marvel на главном экране, данные получаются через Marvel API.
2. Экран с подробной информацией о герое, включая его изображение, имя и описание.
3. В случае проблемы с сетью или сервером отображается ошибка.
4. Переход между экранами: по нажатию на героя открывается экран с его информацией.

## Технологии

1. **Retrofit**: для выполнения HTTP-запросов к Marvel API.
2. **Moshi**: для конвертации JSON в объекты Kotlin.
3. **Coil**: для загрузки изображений героев из сети.
4. **Jetpack Compose**: для создания UI.
5. **Coroutines**: для асинхронных операций с сетью.
6. **Lazy List**: для отображения списка героев.
7. **SnapFlingBehavior**: для создания эффекта прокрутки списка.

## API

- Для получения списка героев используется GET запрос `/public/characters` из Marvel API.
- Для получения информации о герое используется GET запрос `characters/{characterId}` из Marvel API.

## Критерии приёмки

1. Приложение должно успешно загружать данные о героях из сети.
2. Если данные не могут быть загружены (ошибка сети или сервера), отображается произвольная ошибка.
3. В приложении должны быть два экрана:
   - Главный экран с прокручиваемым списком героев.
   - Экран с подробной информацией о герое.
4. Использование Retrofit для работы с сетью и Moshi для конвертации JSON.
5. Приложение должно быть залито на GitHub с созданным Pull Request.
