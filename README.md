# Лабораторная работа №3: Добавление локального хранилища для списка героев Marvel

## Описание

Лабораторная работа является продолжением **Лабораторной работы №2**. Целью данной работы является интеграция локального хранилища для сохранения списка героев Marvel, используя библиотеку **Room**. Данные героев загружаются из Marvel API, сохраняются в локальную базу данных, а также отображаются на главном экране и экране с информацией о герое.

---

## Критерии приемки

1. **Работа с локальной базой данных:**
   - Для работы с локальным хранилищем используется библиотека **Room**.

2. **Сохранение данных из Marvel API:**
   - При выполнении GET-запроса `/public/characters` данные о героях сохраняются в локальную базу данных.

3. **Отображение списка героев на главном экране:**
   - На главном экране отображается список героев, загруженный из локальной базы данных.
   - При этом во время запроса из базы данных отправляется сетевой запрос для обновления данных в локальном хранилище.

4. **Отображение данных на экране героя:**
   - На экране информации о герое сначала осуществляется запрос в локальную базу данных.
   - Если запись отсутствует, отправляется сетевой запрос, после успешного выполнения которого данные о герое сохраняются в базу данных.

5. **Маппинг данных:**
   - Создан маппер для преобразования данных между различными слоями:
     - `CharacterDTO` → `CharacterUI`
     - `CharacterEntity` → `CharacterUI`
     - `CharacterDTO` → `CharacterEntity`

6. **Репозиторий:**
   - Добавлен репозиторий для обработки данных из сети и базы данных, обеспечивающий единый интерфейс работы с данными.

---

## Требования

- Подключить зависимости для работы с **Room** и **Retrofit**.
- Обеспечить корректную обработку ошибок при запросах в сеть и базу данных.
- Грамотно организовать архитектуру приложения, используя принципы Clean Architecture:
  - UI слой для отображения данных.
  - Data слой для взаимодействия с сетью и базой данных.
  - Domain слой для бизнес-логики.

---

## Структура проекта

- **UI слой:**
  - Главный экран с отображением списка героев.
  - Экран с подробной информацией о герое.

- **Data слой:**
  - Data Transfer Object (DTO) для работы с Marvel API.
  - Entity классы для хранения данных в локальной базе данных.
  - Репозиторий для обработки данных из сети и базы данных.

- **Мапперы:**
  - Классы для преобразования данных между DTO, Entity и UI слоями.

---

## Инструкция по запуску

1. Склонируйте репозиторий.
2. Настройте API ключи для работы с Marvel API.
3. Убедитесь, что устройство поддерживает работу с локальной базой данных.
4. Запустите приложение и проверьте:
   - Отображение списка героев на главном экране.
   - Корректное обновление данных при запросе в сеть.
   - Отображение информации о герое на втором экране.

---

## Зависимости

- Room (для работы с локальной базой данных)
- Retrofit (для работы с сетью)
- Coroutine (для асинхронной обработки данных)
- Kotlin (основной язык разработки)
- Jetpack Compose (UI)
